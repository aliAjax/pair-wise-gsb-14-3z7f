# 油品价格维护（邻站差价联审）

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

这是一个功能最小闭环前端项目，数据保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。

## 业务规则

1. **调价单**：填写调价站点、油品、拟定售价、参照站（邻站）与生效区间。
2. **区间不重叠**：同站同油品的生效区间不能交叠（首尾相接允许），冲突时显示站点、油品、差额、冲突区间与命中的规则。
3. **邻站差价联审**：与参照站每升差额超过 **三角五分（0.35 元/升）** 时，必须填写调价依据，并经具名复核人通过（制单与复核须分离）；阈值内免人工复核，提交即生效。
4. **冻结快照**：复核通过后，参与站点（调价站与参照站）该油品价格写成冻结快照，解除前区间内不能单独调价。
5. **解除**：冻结解除须由原复核人本人执行（免复核单可由具名站长执行），并另存解除说明；解除后区间释放、可重新调价。
6. **重新载入**：调价单、区间占用、冻结快照与解除说明通过 ID 互相指针对应，刷新/重载后状态与审计链完整保留。

## 数据结构

- 领域模型与阈值常量：`src/price/model.ts`
- Pinia 状态、规则校验、联审/冻结/解除流程与持久化：`src/price/store.ts`
- 界面（调价单录入、阻挡提示、联审操作、快照与解除说明、站点价格表）：`src/App.vue`
